01 / Persistent context

A project is more
than a prompt.

The brief changes. The evidence grows. The workspace keeps up.

Organize files by purpose, scope the context for each run, and keep the useful artifacts when the task ends. A new instruction should not mean starting from scratch.

03 / Explicit boundaries

Autonomy with
a sense of place.

Give the agent a clear working area and keep the consequential decisions visible.

Scope tools to the task. Ask for review before a write. Make the limits part of the workspace, so they travel with the work rather than living in a separate conversation.
