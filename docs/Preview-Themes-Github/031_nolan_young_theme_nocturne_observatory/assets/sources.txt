MODIFICATIONS
Images were proportionally resized and JPEG-encoded at quality 88 for local
static hosting. CSS crops them to their layout containers and applies dark
display overlays where needed for text legibility. No generative edits,
content replacement, watermark removal, or compositing were performed.
Source files remain available at the original URLs above.

ON-PAGE ATTRIBUTION
Each image has an adjacent visible credit linked to its source and to
CC BY 4.0. The category-switching menu updates the credit and alt text with
the image. A footer note explains the fictional venue, independence from
ESO, and layout modifications, and links to this source record.
