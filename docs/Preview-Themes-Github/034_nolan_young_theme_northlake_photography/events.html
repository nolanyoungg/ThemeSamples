Can you photograph a small celebration?

Yes. Intimate anniversaries, reunions, birthdays, and community gatherings are a natural fit.

Will you arrange group photographs?

We can set aside a short, planned window for those. The rest of the time is focused on the event as it unfolds.

How is coverage planned?

We begin with the event schedule, location, lighting, and the moments you want covered, then agree on a clear scope.
